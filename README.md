\# biom5350-seq-tools

A simple Python tool for analyzing DNA sequences from FASTA files.

\#\# Usage

Run the script using:

\`\`\`bash

python gc_content.py example.fasta

\`\`\`

\#\# Output

The script calculates the length, GC content, and AT content of each sequence, and reports the mean GC content across all sequences.
